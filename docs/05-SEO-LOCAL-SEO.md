# SEO & Local Search Specification

## 1. Important expectation

The client wants the website to appear at the top when people search for
electrician/HVAC/maintenance services in Lahore.

No developer can guarantee a #1 Google position. The implementation
should maximize technical quality, relevance, local signals, useful
content and conversion readiness. Ranking also depends on competition,
authority, links, reviews, proximity, search intent and Google's
systems.

## 4. Titles

Rules: - unique - concise - accurately describe page - location only
where useful - avoid keyword stuffing

Examples: - `HVAC Services in Lahore | A-One Maintenance Service` -
`AC Installation & Repair in Lahore | A-One Maintenance` -
`Commercial Chiller Maintenance Lahore | A-One Maintenance` -
`Annual Maintenance Contracts (AMC) | A-One Maintenance`

## 5. Meta descriptions

Write natural summaries that explain: - service - location -
differentiator - CTA

Do not write a keyword list.

## 6. URL structure

Use:

``` text
/services/hvac
/services/ac-installation
/services/chiller
/solutions/commercial
/projects/commercial-hvac-lahore
/blogs/how-often-should-you-service-an-ac
```

Avoid:

``` text
/service?id=123
/services/page1
/lahore-ac-repair-best-cheap-fast
```

## 7. Local SEO

Set up/verify: - Google Business Profile - correct business name -
correct category/categories - accurate address if eligible - accurate
service area - real phone - real website - real hours - real
photographs - service descriptions - genuine reviews

Google states service-area businesses can define service areas by
cities/postcodes/areas, with up to 20 service areas, and the overall
area should generally be within about two hours' driving time from the
base. Use only areas actually served.

## 8. NAP consistency

Keep consistent: - business name - address - phone

Across: - website - Google Business Profile - legitimate directories -
social profiles - company documents where appropriate

## 9. Reviews

Build a genuine review process.

Allowed: - ask real customers for honest reviews - provide a direct
review link - respond professionally to reviews

Do not: - buy reviews - offer discounts for reviews - ask customers to
write specific wording - generate fake reviews - selectively manipulate
ratings

## 10. Structured data

### Local business

Include accurate: - name - address where appropriate - telephone - URL -
logo - hours where confirmed - service area information where schema
supports it

Use the most specific applicable LocalBusiness subtype.

### Organization

Use for company identity and logo.

### BreadcrumbList

Use on deeper pages.

### BlogPosting/Article

Use on article pages.

### Reviews

Do not add self-serving aggregate review markup merely to obtain stars.
Follow Google's current review snippet guidelines.

## 11. Internal linking

Home links to major services.

Each service links to: - related services - relevant industries -
relevant projects - quote/contact

Project pages link to: - service - solution/industry - quote

Blog posts link to: - service - project - quote

## 12. Content strategy

Publish genuinely useful local technical content: - AC maintenance
checklist for Lahore summers - split vs inverter AC maintenance - signs
a commercial chiller needs maintenance - HVAC preventive maintenance
checklist - duct cleaning and airflow basics - washing machine common
faults - freezer cooling problems - when to call a professional
electrician - office HVAC AMC planning - hospital HVAC maintenance
considerations - kitchen ventilation basics

Every article should be based on actual expertise and reviewed by the
business/team where technical claims matter.

## 13. Project-led SEO

Projects are valuable because they create original evidence.

Example: \> Commercial HVAC Maintenance Project --- Lahore

Include: - site type - actual scope - equipment/system - photos -
problem - work - outcome if measured

Never invent outcomes.

## 14. Area strategy

Start with: `/areas-we-serve`

Include actual Lahore areas served.

Only create separate area pages when each has meaningful unique
information, such as: - real project in that area - service
availability - local service considerations - unique FAQs -
photos/evidence

Avoid mass-generated "AC repair in \[every Lahore neighborhood\]" pages.

## 16. Sitemap

Generate automatically from actual indexable routes.

Submit: `/sitemap.xml`

Only include canonical URLs that should appear in search.

## 17. robots.txt

Use it for crawl management, not as a substitute for `noindex`.

Do not accidentally block: - CSS - JS - images required for rendering

## 18. Google Search Console

Before/after launch: - verify domain - submit sitemap - inspect
important URLs - monitor indexing - monitor Core Web Vitals - monitor
queries - monitor manual actions/security issues

## 19. Analytics events

Track: - `phone_click` - `whatsapp_click` - `quote_started` -
`quote_submitted` - `contact_submitted` - `project_view` -
`service_view` - `equipment_inquiry` - `directions_click`

Do not collect unnecessary personal information in analytics.
