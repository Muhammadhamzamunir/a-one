# UX/UI Design Specification --- A-One Maintenance Service

## 1. Design concept

**Engineering Confidence + Service Accessibility**

The site should feel like a professional technical contractor rather
than a small informal repair listing.

Visual keywords: - industrial - technical - clean - reliable - precise -
premium - approachable

## 2. Brand interpretation

The supplied logo combines: - mechanical gear - tools - large A1/A-One
mark - blue/cyan engineering colors - red accent - dark charcoal
typography

The letterhead reinforces a service/maintenance identity.

Do not redraw the logo unless the client asks for a brand refresh. Use a
cleaned, high-resolution transparent version for the website if
available.

## 3. Color system

### Primary

-   Deep Navy/Blue: `#172A88`
-   Technical Blue: `#1266C4`
-   Cyan Accent: `#16A7D9`

### Neutral

-   Charcoal: `#202124`
-   Graphite: `#34363A`
-   Light Gray: `#F4F6F8`
-   White: `#FFFFFF`

### Accent

-   A-One Red: `#D91F2B`
-   Success: use a restrained accessible green only where status UI
    requires it.

Red should be an accent, not the dominant background.

## 4. Typography

Recommended: - Headings: Manrope or Plus Jakarta Sans - Body: Inter

Use: - strong weight contrast - generous line-height - short
paragraphs - technical labels in uppercase sparingly

Avoid: - decorative fonts - too many font families - tiny body text

## 5. Layout

Desktop max content width: - 1200--1280px

Spacing: - large section spacing - 8px-based spacing system - generous
white space

Cards: - medium radius, not excessive rounded "startup" cards - subtle
border - light shadow only when useful

## 6. Header

Desktop: - logo - Services - Solutions - Projects - About - Blogs -
Contact - CTA

Top utility strip: - Lahore Service Area - phone - WhatsApp

Mobile: - logo - menu - sticky contact bar

## 7. Hero

Recommended composition: - left: headline + paragraph + CTA - right:
real technician/HVAC/project image - subtle technical grid/blueprint
background - small floating service chips - minimal parallax

Example: \> **Technical Maintenance & HVAC Solutions Across Lahore**

Subtext: \> Installation, repair, preventive maintenance and project
solutions for residential, commercial and industrial environments.

CTA: \> Request a Site Visit

Secondary: \> Call +92 302 9511041

## 8. Service cards

Each card: - icon - title - one-line explanation - "Explore Service" -
optional equipment tags

Do not overload cards with paragraphs.

## 9. Corporate credibility

Use a section resembling a project capability sheet: - HVAC -
Electrical - Chiller - Ducting - Ventilation - Fire Fighting - Appliance
Maintenance - AMC

Then a "From Survey to Maintenance" process timeline.

## 10. Project case-study UI

Large image + technical summary.

Example labels: - PROJECT TYPE - LOCATION - SCOPE - SYSTEM - STATUS

The design should support corporate visitors who want evidence rather
than marketing slogans.

## 11. Industries UI

Use a structured grid: - Residential - Commercial - Industrial -
Hospitals - Offices & IT - Retail - Apartments & Villas - Automotive -
Manufacturing - Resorts

## 12. CTA system

Primary CTA: - Request a Quote

Secondary: - WhatsApp - Call

CTA text should describe the action: - Request a Site Visit - Get a
Project Quote - Discuss AMC - Talk to a Technical Expert

## 13. Accessibility

-   WCAG-oriented contrast
-   visible focus states
-   keyboard navigation
-   semantic headings
-   labels for forms
-   descriptive link text
-   no information conveyed by color alone
-   reduced-motion mode
-   alt text for meaningful images

## 14. Mobile UX

Mobile is a first-class design, not a desktop shrink.

Persistent bottom bar: - Call - WhatsApp - Quote

Keep it small and non-blocking.

## 15. Trust design

Trust should come from evidence: - real project images - real team
photos - real location - real customer testimonials - actual brands
serviced - actual project scopes - clear contact information

Avoid fake counters such as "10,000+ happy customers" until the client
can document them.

## 16. Footer

Columns: - Company - Services - Solutions - Blogs - Contact

Include: - address - phone - email - service area - WhatsApp - social
links if real - privacy - terms

## 17. Corporate partner section

Later version: \> **Technical Service & Installation Partnerships**

Explain capabilities: - product installation - after-sales service -
maintenance support - project execution - site surveys - technical
consultation

Use only verified partnership/authorization statements.

## 18. Animation rules

Every animation must answer one of: - show hierarchy - guide attention -
communicate a process - make an interaction feel responsive

If it does none of these, remove it.
