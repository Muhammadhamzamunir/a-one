# Product Requirements Document --- A-One Maintenance Service

## 1. Product summary

A-One Maintenance Service needs a corporate-grade website for
Lahore-wide technical services. The product is primarily a
lead-generation and credibility platform, not an ecommerce storefront.

## 2. Users

### Residential

-   Homeowners
-   Apartment residents
-   Luxury villa owners
-   Landlords

### Commercial

-   Office managers
-   Facility managers
-   Retail owners
-   Restaurants and kitchens
-   IT companies
-   Automotive showrooms

### Industrial/institutional

-   Factories
-   Manufacturing units
-   Hospitals
-   Resorts
-   Large buildings
-   Contractors and project managers

### Corporate/procurement

-   Procurement teams
-   Admin/facility departments
-   National companies
-   Multinational companies
-   Equipment/product companies looking for installation/service
    partners

## 3. Primary user tasks

1.  Find a relevant service.
2.  Check whether A-One serves their Lahore area.
3.  Understand whether A-One handles their equipment/system.
4.  Call immediately.
5.  WhatsApp immediately.
6.  Request a site visit/quote.
7.  Review completed projects.
8.  Check industries served.
9.  Understand AMC options.
10. Verify contact/company information.

## 4. Primary conversion events

-   Phone click
-   WhatsApp click
-   Quote form submit
-   Contact form submit
-   Service inquiry
-   Project inquiry
-   AMC inquiry
-   Partner inquiry
-   Email click
-   Map/directions click

## 5. Home page requirements

### Hero

Headline: \> HVAC, Electrical & Maintenance Solutions Across Lahore

Supporting text: \> Professional installation, repair, maintenance and
technical solutions for homes, offices, commercial sites and larger
facilities.

CTA: - Call Now - WhatsApp - Request a Quote

Hero visual: - real technician/HVAC/project image preferred - supplied
A-One logo - no stock-photo overload

### Trust section

Use only verified facts: - Lahore-wide service - trained/expert team if
verified - residential and commercial capability - AMC - project
experience - consultation

### Services

Show 8--10 major categories.

### Corporate section

Explain: - site survey - design/solution - supply - installation -
commissioning - repair - preventive maintenance - AMC

### Projects

Case-study cards: - project type - location - scope - equipment/system -
result - photos

## 6. Services

### HVAC

Include: - HVAC design - installation - repair - preventive
maintenance - troubleshooting - system optimization

### AC

Include: - split - inverter - cassette - duct type - installation -
repair - maintenance

### Chiller

Include: - chiller maintenance - troubleshooting -
installation/support - commercial building systems - commissioning if
actually offered

### Ducting & ventilation

Include: - duct design - duct fabrication/installation if actually
offered - kitchen ventilation - exhaust/ventilation - airflow-related
solutions

### Electrical

Include: - residential electrical work - commercial electrical
maintenance - installation - troubleshooting - equipment connections -
project electrical support

### Appliances

Include: - washing machine repair/service - refrigerator/freezer
repair/service - water cooler - geyser - heater - related equipment

### Fire fighting

Include: - supply - installation - maintenance - only the exact scope
confirmed by the client

### AMC

Explain: - planned visits - preventive inspection - maintenance
schedule - priority response if contract includes it - reporting -
asset/system record - quotation/contact CTA

Each page must have unique content, real use cases and relevant

## 8. Projects

Project detail fields: - title - project category - location - client
name if permission exists - project duration - scope -
systems/equipment - challenges - work completed - photographs -
outcome - related services - inquiry CTA

Never fabricate project names, clients, project values or outcomes.

## 9. Used equipment

The client says they buy and sell used: - ACs - coolers - freezers -
washing machines

Requirements: - equipment listing - condition - model - age/year if
known - working status - photos - price only if approved -
inspection/warranty information if applicable - WhatsApp inquiry - clear
used-equipment terms

## 10. Contact/quote form

Fields: - Name - Phone - Email optional - Company optional - Service
category - Property/project type - Area in Lahore - Preferred contact
method - Description - Optional photo/file upload - consent checkbox

Do not request unnecessary sensitive data.

## 11. Admin

Admin should manage: - services - projects - testimonials - FAQs - blogs - posts - used equipment - brands - leads/quote requests - contact requests - media metadata - SEO metadata

Admin roles: - Super Admin - Content Manager - Lead Manager

## 12. Non-functional requirements

-   responsive 320px+
-   modern Chromium/Firefox/Safari support
-   keyboard accessible
-   semantic HTML
-   optimized images
-   lazy loading below the fold
-   server-rendered public content
-   secure API
-   audit logging for important admin actions
-   rate limiting
-   error monitoring
-   backups
-   privacy-aware analytics

## 13. Acceptance criteria

A page is complete when: - it has unique useful content - it has a clear
CTA - it is accessible - it works on mobile - metadata is correct -
images have appropriate alt text - structured data is valid where
applicable - no fake claims are present - internal links are present -
loading behavior is acceptable - forms validate client and server side
